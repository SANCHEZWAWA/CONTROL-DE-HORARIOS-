
# Sistema de Control de Horarios

## Objetivo
Desarrollar un sistema de control de horarios que permita organizar, consultar y administrar los horarios de manera sencilla y ordenada.

## Integrantes
- Estefanía González Martínez
- Sofía Hernández Ortiz
- Alfredo Reséndiz Sánchez
- Zahid Mendoza Moran

## Estructura del proyecto
- docs: Documentación del sistema.
- prototipos: Diseños de las pantallas.
- src: Código fuente del sistema.

## Funciones principales
- Registrar horarios.
- Consultar horarios.
- Modificar horarios.
- Organizar la información de los horarios.
